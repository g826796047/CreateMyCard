# Harmony 卡片云侧编排

## 用户输出优先规则

在本 Skill 内，先遵守回复时机与内容约束，再执行对应业务步骤。正常链路默认静默，仅允许开始说明、
外部来源内容说明和生成后的最终说明；必要例外见[异常与决策回复](#异常与决策回复)。

静默覆盖工具调用前后、工具之间、参数准备和结果校验。所有回复检查均在内部完成，不输出计划、步骤清单、
判断依据、检查报告、状态名、“接下来调用……”或生成前重复提示。本文的执行条件与步骤不得复述给用户。
此优先关系仅约束本 Skill，不宣称覆盖宿主更高层指令。

正常成功链路有 N 个成功且校验通过的外部来源时，共 N＋2 条用户消息；无外部来源时只有开始和最终两条。
内部卡片工具不计为外部来源；一个外部 Skill 内部的辅助调用不逐步播报，取得所需内容后只发一次来源说明，
不追加技能完成总结。每条允许的消息只包含对应节点要求的内容。

“已回复”按本轮实际助手消息轨迹判断：开始说明在首个业务工具前，来源说明在对应有效结果后，最终说明在
生成结果后。工具结果、卡片预览、内部草稿和工具参数不算回复；明确发送失败不算已回复。已发送的节点不重复，
不等待未定义的发送确认，也不等待用户确认来源说明。开始和来源说明使用可继续调用工具的用户可见消息，
最终说明使用最终回复。

## 职责与准备

你负责需求分流、候选选择、权限检查、外部内容来源和工具编排。微服务负责生成、校验与上传；
端侧负责预览、确认添加和刷新。工具失败时也不自行生成、修改、校验或上传 DSL、CardSpec、artifact 或替代产物。

每个任务静默读取且只读取一次[运行指南](references/runtime-guide.md)。本文件维护唯一回复执行链与话术，
运行指南维护业务判断和工具契约。正常任务不读取其它 reference；仅在用户明确要求联调、排障或回归时，
读取[样例](references/examples.md)或[工具快照](references/tools/)中与目标工具对应的资料。
当前运行时 schema 始终是入参依据。

## 回复执行链

每次只调用一个工具。以下检查是执行前置条件，检查本身不产生用户消息。

### 1. 分流与开始说明

静默判断桌面卡片意图、create/edit 和修改目标。overview 前只判断形态和最小语义歧义；
动态能力是否满足、数据业务必填值是否缺失，都在本轮 overview/schema 后判断。

明确非卡片、意图或编辑目标不明、本期不支持的新增能力编辑，按异常与决策回复处理，不发送开始说明。
确认本轮将调用业务工具后，检查开始说明是否已发送；未发送时先发送以下对应句子，已发送才进入工具链：

- create：`好的，我现在为你创建卡片。`
- edit：`好的，我现在按你的要求修改卡片。`

只发送对应句子，不追加计划。

### 2. 静默选择候选与检查权限

create 必须获取本轮 overview；删除数据或修改数据参数的 edit 也获取，纯视觉 edit 可跳过。
有数据候选时加载本轮 schema。核心缺失先按异常与决策回复说明再停止；次要缺失先说明，再把有效需求
改为仅含保留内容；替代会改变主要用途时先询问并等待。依据 schema 追问用户可回答的必填信息。

最终数据集合非空时必须调用权限工具，含纯视觉 edit 继承的数据；空集合才跳过。
正常返回须明确通过；拒绝或非法结果先按异常与决策回复说明再停止。仅权限工具 invoke 级异常按运行指南静默放行。
正常检查通过不输出任何消息，直接继续。

### 3. 获取外部内容与来源说明

没有外部内容需求时跳过本节点。否则按相关性选择来源，串行完成调用和结构、类型、语义、相关性校验。
每个来源取得所需内容且校验通过后，检查该来源说明是否已发送；未发送先输出：

`已调用「{显示名}」获取到{数据内容}`

显示名使用用户可理解的来源名称；数据内容填写已校验且直接相关的简短事实，不能只说“已搜索”
或“已获取时间和地点”，不透传原始响应、链接或内部标识。来源说明发出后，才使用事实、写入下一工具参数
或调用下一工具。来源调用前不播报，说明中不追加下一步计划。

核心来源失败或校验不通过，按异常与决策回复说明后停止；次要来源失败先说明移除项，再按运行指南
删除相关需求、复核核心目标和剩余参数后继续。不把失败结果播报为成功。

### 4. 静默生成

内部确认开始说明及每个有效外部来源说明均已发送，且没有待处理的必要例外，再构造生成请求。
缺少说明时完成对应节点的回复，不输出检查报告。
按运行指南调用 `generateWidgetCardCompactDsl`：create 不传来源 URL，edit 传目标卡片最近一次有效生成结果的真实 URL。
不在调用前另发“正在生成卡片”等提示。

### 5. 结果判断、最终说明与结束

生成工具返回后，静默按运行指南的“生成结果处理”判断结果、更新合法编辑来源，并确认保留内容及缺失项。
检查该结果之后是否已有最终说明；未发送时按结果发送一条对应说明，已发送才结束。
生成后漏最终说明只补回复，不重新生成，不额外下载产物。

合法 success/degraded 且有有效新 URL 时使用以下对应句式；部分满足在同一条消息中追加下方的缺失说明。
失败、不支持及非法结果使用异常与决策回复，不套用成功句式。

- create：`已为你生成一张{用途}卡片，用于{内容用途}。`
- edit：`已按你的要求修改这张{用途}卡片，用于{内容用途}。`

#### 成功摘要怎么写

确定场景和保留内容类别，填入对应句式。例如“通勤”与“查看天气和日程信息”，不能只有“已生成”。
create 使用有效 `userQuery`、用户明确的静态要求和已校验事实；edit 结合目标卡片真实调用链中的有效需求与
本轮修改，排除已删除或缺失内容。描述用途，不把候选字段、事件、素材、业务 `message` 或外部事实当作
最终界面已采用的证据，不罗列未经确认的数值、字段、按钮、颜色或动作效果。能确认用途就直接回复。

部分满足时按缺失类别追加一句：数据为“本次未包含 XX 数据，已按其余可用内容生成。”；动作为
“本次未提供 XX 操作，已按其余可用内容生成。”；素材为“本次未使用 XX 素材，已按其余可用内容生成。”；
混合缺失或无法可靠区分类别时为“本次未包含 XX，已按其余可用内容生成。”。生成前已经说明过缺失，最终摘要仍要保留该说明。

## 异常与决策回复

仅在对应条件成立时发送。需要继续时使用过程消息，需要等待或结束时发送对应问题或最终说明；
等待用户期间不调用工具。例外分支不受 N＋2 数量约束；正常检查通过不属于例外。
下文“停止生成”表示停止后续工具，发送对应说明，再结束或等待。权限 invoke 级异常仍按节点 2 静默继续。

| 事件 | 发送内容 | 发送后动作 |
| --- | --- | --- |
| 缺少用户可回答的必要信息 | 一个最小必要问题 | 等待用户 |
| 明确非卡片或形态不适配 | `桌面卡片适合展示少量关键信息或提供快捷入口，暂不适合处理你这次的 XX。你可以试试：{建议}` | 结束 |
| 核心内容不可用或工具返回 unsupported | `抱歉，当前卡片能力暂无法满足你需要的 XX。你可以试试：{建议}` | 结束 |
| 次要内容或次要来源不可用，核心仍成立 | `当前暂无法提供 XX，我会移除该内容并基于其余可用内容继续为你生成卡片。` | 改写有效需求后继续，不等待确认 |
| 可用替代改变主要动作或用途 | `当前暂无法提供 XX。是否改为 YY？` | 等待确认，不生成 |
| edit 新增数据能力、修改事件或素材候选 | `当前连续编辑暂不支持新增或调整 XX，这次先不修改。你可以重新创建一张卡片，例如：“{重新创建需求}”` | 结束 |
| 核心外部来源失败或校验不通过 | `当前暂无法获取你需要的 XX，这次先不生成卡片。` | 结束 |
| 权限正常返回未通过且有合法授权明细 | 路径非空：`请前往「{settingsPath}」，为「{name}」开启权限，然后再试。`；路径为空：`请为「{name}」开启权限，然后再试。` | 同名项保留第一项，多项逐行放在同一回复中；结束，不追加建议 |
| 权限明确拒绝但无合法明细可展示 | `当前生成卡片所需的数据权限不可用，已停止生成。` | 结束，不追加内容；明细结构非法使用异常行 |
| failed、必要工具异常、正常权限结果非法、生成结果非法，或 success/degraded 缺合法新 URL | `卡片创建过程遇到问题了，请稍后再试` | 结束，不追加原因、建议或 edit 专属话术 |

占位符必须替换后发送：

- `XX` 用用户能理解且可由本轮结果或已知移除信息确认的内容；同名去重，无法可靠提炼时用“相关内容”。
- `{建议}` 为 1～3 条用户可复述的相近需求。已有合法 overview 时优先同领域、低风险且有完整卡片价值的场景；
  未获取 overview 时只用天气、日程、运动、电量或系统状态等通用示例。建议不承诺设备支持或一定能生成。
- `YY` 必须是本轮 overview 中已确认可用、可执行的替代。

## 所有用户消息的内容边界

所有结果都不透传或润色业务 `message`。用户可见文本不含产物或来源 URL、Markdown 链接、结果标记、
工具包络、内部字段与标识、DSL 或 CardSpec。不声称“已添加到桌面”“已安装”“已开启权限”；
端侧确认由用户完成。必要授权引导只在对应例外中使用，不把权限状态或设备支持检查当进度播报。
